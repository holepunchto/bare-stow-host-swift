# bare-stow-host-swift

Host side of the [bare-stow](https://github.com/holepunchto/bare-stow) lifecycle for Swift. The Swift counterpart of [bare-stow-host](https://github.com/holepunchto/bare-stow-host): it multiplexes a control channel and a user data channel over a byte transport to a stowed bundle, and layers readiness, termination, and exit reporting on top. Harnesses generated by `bare-stow` use it to drive the bundles they boot.

## Installation

```swift
dependencies: [
  .package(url: "https://github.com/holepunchto/bare-stow-host-swift", from: "<tag>")
]
```

Then add `BareStowHost` to the dependencies of your target:

```swift
.product(name: "BareStowHost", package: "bare-stow-host-swift")
```

## Usage

```swift
import BareSidecar
import BareStowHost

extension Sidecar: @retroactive Transport {}

let sidecar = try await Sidecar.spawn(bundle)
let ipc = IPC(sidecar, kill: { sidecar.kill() })

Task {
  switch await sidecar.wait() {
  case .exit(let code): ipc.exited(code: code)
  case .signal(let signal): ipc.exited(code: nil, signal: signal)
  }
}

try await ipc.ready()
try await ipc.write(Data("hello".utf8))

let code = await ipc.terminate()
```

Any `AsyncSequence` of `Data` with an `async` `write(_:)` can be wrapped by conforming it to `Transport`, such as a `Sidecar` from [bare-sidecar-swift](https://github.com/holepunchto/bare-sidecar-swift).

## Protocol

Every frame is a 4-byte little-endian length followed by that many bytes: A 1-byte tag and the payload. The tag is `0x00` for a control frame, whose payload is a UTF-8 JSON object carrying its `type`, and `0x01` for a user data frame. See [bare-stow-protocol](https://github.com/holepunchto/bare-stow-protocol) for the control frames.
